---
title: Static by default
date: 2026-07-19
summary: Publishing gets easier when the output has fewer moving parts.
published: true
tags: [web]
---

For a personal site, static generation is not only a performance choice. It is a durability choice.

The source stays readable, the build can be reproduced, and the public version does not depend on a database remaining healthy. Dynamic behavior can still be added where it earns its place.

<Callout title="Working rule">
Keep content as files. Add runtime state only for interactions that cannot be expressed in the document itself.
</Callout>
